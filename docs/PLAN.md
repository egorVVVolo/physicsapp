# План MVP — образовательное приложение по физике (рабочее имя: Physicsapp)

Версия 1.2 · 10 ноября 2026 · статус: **план согласован владельцем**

**Изменения в 1.2 (решения владельца 9–10 ноября, после разбора `docs/research/review-2026-11-10.md`):**
1. **Сначала пилотная сборка:** 3 урока, без аккаунтов и без теста уровня, раздача по веб-ссылке. Онбординг, аккаунты, вкладки Practice и Progress, ещё 2 урока — после неё (это «полный MVP»).
2. **Один путь в уроке** (уровень экзамена). Разобранный пример появляется только после ошибки. Отдельный путь для новичка — после пилота, если данные покажут, что он нужен.
3. **6 типов шагов** вместо 12 (см. `docs/LESSON_FRAMEWORK.md`, раздел 5).
4. **Контрольная точка «вау»** — одна полная 10-минутная сессия на телефоне, а не Motion Lab.
5. **В пилоте нет онбординга:** первый экран — сразу первый вопрос со сценой.
6. Урок = сессии по ~10 минут (Core → Exam workout → Tricky cases). Сцена и график — отдельные виды, никогда рядом.

**Изменения в 1.1 (1 ноября):** онбординг с адаптивной оценкой уровня · аккаунт Apple + Google · heatmap · challenge-шаги · резерв 2 недели. Всё это остаётся в полном MVP, но строится после пилотной сборки.

> Рабочее имя временное. В коде оно хранится в одной константе (`APP_NAME`), чтобы переименование заняло минуту.

## 0. Summary

**Что делаем:** мобильное приложение (iOS + Android + веб-версия из одного кода) с короткими интерактивными уроками физики под экзамен **Pearson Edexcel International A Level, Unit 1 (WPH11)**. Первый модуль — **Kinematics**.

**Главная идея продукта:** понимание как в Brilliant (большая интерактивная сцена, которую можно трогать) + честная подготовка к экзамену (вопросы в стиле экзамена, единицы, типичные ошибки). Brilliant не готовит к экзаменам, а приложения для подготовки — скучные банки вопросов. Мы занимаем промежуток между ними.

**Зачем:** (1) сильный кейс для поступления — реальные пользователи и измеренный результат; (2) первый шаг к бизнесу. Деньги — потом.

**Ограничения (факты):**

| | |
|---|---|
| Команда | 1 человек (Егор) + Claude Code |
| Время владельца | ~2 ч/неделю → **~16 часов за 8 недель** (+4 ч резерва) |
| Срок MVP | цель — 8 недель (≈ до конца декабря 2026), жёсткий предел — 10 недель (2 недели резерва) |
| Бюджет | $0 на этапе MVP; Apple Developer ($99/год) и Google Play ($25) — можно оплатить, когда понадобится публикация |
| Стек | Expo (React Native) + TypeScript |
| Язык | интерфейс и контент — английский; работа с владельцем — русский |

**Что из этого следует:** код пишет Claude Code, а 2 часа Егора уходят на решения, проверку физики, просмотр результата на телефоне и тесты с одноклассниками.

**Порядок:** сначала **пилотная сборка** — 3 урока (в каждом Core-сессия ~10 минут и Exam workout), прогресс хранится на устройстве, раздача по веб-ссылке. Потом **полный MVP**: ещё 2 урока, онбординг с оценкой уровня, аккаунты, Practice, Progress. Каждый урок должен быть отличным: анимации, дизайн и захватывающее содержание — главный критерий приёмки.

## 1. Value & success

**Ценность в одну строку:** *See the physics move, then answer like the examiner wants.*

### Пользователь

- **Основной (MVP):** ученик IAL Physics (Year 12 / AS), готовится к Unit 1. Учится с телефона: дорога, перемена, вечер перед тестом. Сессия 5–10 минут.
- **Пилот:** одноклассники в Island School (сильная школа → проверка, что уроки не слишком лёгкие).
- **Потом:** другие международные школы с IAL, британский A level (9PH0), затем AP Physics 1 (США, более платёжеспособный рынок) — на том же ядре физики с другим набором экзаменационных вопросов.

### Альтернативы и наше отличие

| Альтернатива | Что даёт | Чего не даёт (наш шанс) |
|---|---|---|
| Учебник + прошлые экзаменационные работы (PMT, Save My Exams) | Полное покрытие, настоящие вопросы | Нет интуиции: формулы без картинки, никакой обратной связи по ходу |
| Brilliant (Science) | Красивые интерактивные уроки | Популярная физика, не под программу и не под экзамен |
| YouTube / Khan Academy | Бесплатно, объяснения | Пассивно: смотришь, но сам не решаешь |
| Приложения с банками вопросов | Много вопросов | Скучно, нет понимания, нет сцен |
| «Ничего не делать» / зубрить перед тестом | 0 усилий сейчас | Путаница со знаками, графиками и выбором SUVAT |

### Метрики успеха MVP (цели — это `HYPOTHESIS`, а не обещания)

| Метрика | Цель для пилота | Как измеряем |
|---|---|---|
| Пилотных пользователей | 15–30 учеников | Счётчик уникальных установок/сессий |
| Дошли до конца онбординга (Placement или Skip → урок) | ≥ 80% открывших | Аналитика событий |
| Вошли в аккаунт | ≥ 30% (`HYPOTHESIS`, ориентир) | Аналитика событий |
| Прошли первый рекомендованный урок до конца | ≥ 70% начавших | Аналитика событий |
| Начали урок 2 | ≥ 50% прошедших урок 1 | Аналитика |
| Вернулись через 7 дней (D7) | ≥ 25% | Аналитика |
| Верно решили задачу на перенос **без подсказки** | ≥ 60% на уровне Intermediate | Исходы шагов в приложении |
| «Слишком легко» среди сильных учеников | ≤ 30% | Мини-опрос в конце урока (1 тап) |
| «Использовал бы перед экзаменом» | ≥ 50% «да» | Тот же опрос |

Для портфолио важны **реальные числа**, а не красивые. Плохой результат пилота тоже ценен: это повод сделать следующую итерацию, о которой можно честно рассказать.

**Для пилотной сборки** (15–30 человек) считаем **количества, а не проценты**: один человек — это 3–7 процентных пунктов, пороги в процентах будут шумом. В пилотной сборке нет онбординга и входа, поэтому две строки про них измеряются только в полном MVP. Самый полезный сигнал пилота — на каком шаге люди бросают сессию.

## 2. User flows

### 2.1 Первый запуск → оценка уровня → аккаунт (цель: первое взаимодействие со сценой < 30 секунд, весь онбординг ≈ 2 минуты)

> **В пилотной сборке этого раздела нет.** Первый экран пилота — сразу первый вопрос первого урока (сцена + вопрос), без Welcome, Goal, Placement и входа. Всё ниже — полный MVP, строится после пилота. Перед реализацией экран Welcome пересмотреть: мини-сцена «объект + график рядом» отвергнута владельцем.

1. Открыл приложение → **Welcome**: одна строка ценности + живая сцена на фоне (бегущий график) + кнопка **Find my level**. Вход не требуется.
2. **Goal** (1 тап): «What are you studying?» → `Edexcel IAL` · `Other A level` · `Just curious`.
3. **Placement — адаптивная оценка уровня** (≈ 90 секунд, 4–6 вопросов):
   - вопросы **на интерактивных сценах**, а не анкета: предскажи движение, потяни график, выбери траекторию, выбери уравнение;
   - адаптивно: верно → следующий вопрос сложнее, ошибка → проще; покрывает темы всех 5 уроков;
   - первый вопрос — сразу сцена: это и есть первое «вау»;
   - `Skip` доступен всегда (тогда старт с урока 1).
4. **Placement result**: карта тем — например «Graphs: strong · Signs: shaky · Projectiles: not yet» — и рекомендованный старт. Рекомендация не навсегда: любой урок можно открыть.
5. **Save your progress** — предложение войти: `Continue with Apple` · `Continue with Google` · `Not now`. Отказ не блокирует: всё работает без входа, предложение повторится мягко после первого урока.
6. → рекомендованный урок.

Под капотом: с первого запуска пользователь — **анонимный аккаунт** (Supabase). При входе через Apple/Google к нему привязывается личность — результат оценки и прогресс не теряются.

Трения: разрешений не просим, push-уведомлений в MVP нет, вход необязателен.

### 2.2 Урок (основной цикл)

Урок — одна идея, разбитая на **сессии по ~10 минут**. Сессия — то, что человек проходит за один заход.

| Сессия | Что в ней | Когда |
|---|---|---|
| **Core** (~10 мин, 6–8 шагов) | Крючок-предсказание → ещё 1–2 предсказания или выбора графика, которые строят идею → «собери решение» (выбираешь связь и значения со знаками, считает приложение) → «найди ошибку» → один шаг в формате экзамена → итог | Пилот |
| **Exam workout** (~10 мин, 3–4 экзаменационные карточки) | Вопросы в формате Edexcel: командное слово, баллы, единицы; числовой ответ — со встроенным калькулятором | Пилот |
| **Tricky cases** (~10 мин) | Сложные случаи без разобранных примеров, уровень Advanced | После пилота |

Правила шага (подробно — `docs/LESSON_FRAMEWORK.md`, разделы 1a и 4–8):

- **Один путь, уровень экзамена.** Сначала задача; разобранный пример появляется только после ошибки.
- **Сначала предсказание, потом движение.** Анимация не раскрывает ответ до проверки. После `Check` ответ проигрывается на сцене; неверный — «призраком» рядом с настоящим движением.
- **Проигрывание идёт само**, коротко останавливаясь на ключевых событиях с подписью. Кнопок Continue нет.
- **Ученик не считает в уме.** Варианты ответа различимы без вычислений; числовые экзаменационные шаги — с калькулятором.
- **Исходы шага:** independent (сам, с первой попытки) · assisted (с помощью или со второй попытки) · revealed (показан разбор). Шаг-предсказание — одна попытка.
- **Помощь:** до двух уровней (наводка → конкретный шаг метода), потом разбор. Как она вызывается — кнопкой или сама после ошибки — решаем на первом шаге «собери решение» на телефоне.

### 2.3 Повторный визит (почему возвращаются)

> В пилотной сборке повторный визит — это главный экран со списком уроков и кнопкой Continue. Streak, heatmap и вкладка Practice — в полном MVP.

1. Открыл → **Learn**: видно, где остановился, одна большая кнопка **Continue**.
2. Серия дней (streak) + **мини-heatmap текущей недели** (7 клеток) — простая, без давления, без «потеряешь всё». Полная сетка активности — на Progress.
3. **Practice**: 12–15 экзаменационных вопросов по пройденному (можно запускать порциями по 5).
4. (Later) повторение ошибок через несколько дней.

### 2.4 Вторичные сценарии (MVP-минимум)

- **Settings:** аккаунт (войти / выйти / удалить аккаунт), reduced motion, звук/вибрация, пройти оценку уровня заново, сбросить прогресс, «Send feedback» (ссылка на форму), Privacy policy, About.
- Оплата, шаринг — **не в MVP**.

## 3. Screen map & navigation

**Пилотная сборка** — без вкладок и без онбординга:

```
Первый запуск → сразу первый шаг первого урока (сцена + вопрос)

Home (один экран) — 3 урока, у каждого сессии Core и Exam workout со статусом, одна кнопка Continue
  └── Session player (полноэкранный) → Session complete → Home
```

**Полный MVP** (после пилота):

```
First launch:  Welcome → Goal → Placement → Placement result → Save your progress (Apple / Google / Not now) → рекомендованный урок

Main (tab bar, 3 вкладки):
├── Learn      — карта курса Kinematics → Session player → Session complete
├── Practice   — смешанные экзаменационные наборы по пройденным темам (тот же движок)
└── Progress   — серия, уроки, навыки → Settings (иконка в шапке)
```

- **Session player — полноэкранный, без таб-бара**: в сессии ничего не отвлекает, одна главная кнопка внизу.
- **Экзаменационные вопросы живут в двух местах с разной ролью:** Exam workout — по теме одного урока; вкладка Practice — смешанные наборы по нескольким пройденным урокам.
- Эскиз экрана Home для пилота показать владельцу до сборки.

## 4. Screen specs

> В пилотную сборку входят только **Home (упрощённый Learn)**, **Session player** и **Session complete**. Остальные экраны — полный MVP.

### Welcome
- **Purpose:** за 5 секунд показать, чем мы отличаемся, и сразу запустить первый урок.
- **Entry:** первый запуск.
- **Content:** логотип/имя · заголовок (например, «Physics you can move.») · живая мини-сцена (один объект в фокусе; не «объект + график рядом») · строка «Edexcel IAL · Unit 1 · Kinematics».
- **Primary:** `Find my level`.
- **Secondary:** `I already have an account` (вход).
- **States:** first-time (единственное состояние).
- **Notes:** при reduced motion сцена статична.

### Goal
- **Purpose:** узнать программу, чтобы подобрать формулировки и маршрут.
- **Content:** один вопрос, 3 крупных варианта.
- **Primary:** выбор варианта (автопереход).
- **States:** first-time.
- **Notes:** сохраняется в `UserPrefs`, меняется в Settings.

### Placement ⭐ (оценка уровня)
- **Purpose:** за ≈ 90 секунд понять, что человек уже умеет, и одновременно показать главный «вау» продукта.
- **Entry:** Goal; позже — Settings → «Retake placement».
- **Content:** тот же интерфейс, что Session player: сцена + вопрос + одна кнопка. Сверху — тонкий прогресс без числа вопросов (адаптивный тест может закончиться раньше).
- **Primary:** `Check` (без разбора после каждого ответа — только короткая реакция, чтобы не затягивать).
- **Secondary:** `Skip` (в шапке), `I don't know` (засчитывается как ошибка, но без стыда).
- **States:** question · answered · finishing («Building your map…» ≤ 1 с).
- **Notes:** банк из ~10–12 вопросов по 5 темам (по 2 на тему + 1–2 Advanced). Алгоритм простой и объяснимый: старт с Intermediate по теме графиков; верно → тема сложнее/следующая, ошибка → вопрос проще по той же теме. Результат — уровень по каждой теме: `strong` / `shaky` / `not yet`. Это оценка стартовой точки, а не «mastery».

### Placement result
- **Purpose:** показать картину и следующий шаг.
- **Content:** карта 5 тем со статусами (цвет + иконка + текст) · одна фраза-вывод («You read graphs well — start with equations.») · рекомендованный урок.
- **Primary:** `Continue`.
- **Secondary:** `See all lessons`.
- **States:** normal · skipped (без карты: «Start from Lesson 1»).

### Save your progress (вход)
- **Purpose:** привязать аккаунт в момент, когда у человека уже есть что сохранять.
- **Content:** заголовок «Save your level and progress» · 1 строка пользы (синхронизация между телефоном и вебом) · кнопки входа.
- **Primary:** `Continue with Apple` (iOS) / `Continue with Google`.
- **Secondary:** `Not now`.
- **States:** idle · signing in · error («Couldn't sign in — try again or continue without an account») · success.
- **Notes:** Apple требует Sign in with Apple, если в iOS-приложении есть вход через Google. Просим минимум данных. Повторное мягкое предложение — на экране Lesson complete первого урока, дальше не навязываем.

### Learn (карта курса)
- **Purpose:** «где я и что дальше».
- **Entry:** таб, после онбординга, после урока.
- **Content (по приоритету):** карточка **Continue** (следующий урок, % шагов, примерное время) · путь из 5 уроков с уровнями и статусами (not started / in progress / done-independent / done-assisted) и пометками по оценке уровня («You're strong here — optional») · блок Practice (открывается после урока 2) · в шапке: серия дней + **мини-heatmap недели** (7 клеток, сегодня выделено).
- **Primary:** `Continue`.
- **Secondary:** открыть любой урок.
- **States:** first-time (Continue = рекомендованный урок по оценке) · in progress · all done («Practice exam-style questions» + «More modules coming»).
- **Notes:** у каждого урока есть пометка о пункте программы (например, «Spec: motion graphs»).

### Lesson intro (bottom sheet)
- **Purpose:** обозначить цель и уровень до старта.
- **Content:** название · «You'll be able to…» (1–2 пункта) · уровень · пререквизиты · ~время.
- **Primary:** `Start` / `Resume`.
- **States:** new · in progress · completed (`Replay`).

### Session player ⭐ (главный экран продукта)
- **Purpose:** провести через шаги сессии.
- **Entry:** первый запуск (пилот) / Continue / урок на Home.
- **Layout (сверху вниз, один экран без прокрутки — проверяется на 375×667):** тонкий прогресс по шагам + `×` · условие задачи (полное, до 3 строк, видно всё время) · **вид: сцена или график, один за раз, не меньше половины высоты** · слот фиксированной высоты (вопрос до проверки, обратная связь после) · ответы в один ряд или лоток «собери решение» · одна главная кнопка.
- **Primary:** `Check` → неактивна, пока идёт проигрывание → `Next`.
- **Secondary:** переключатель Scene / Graph · маленькая кнопка повтора · тап по сцене — пауза · после проигрывания — перетаскивание по сцене для перемотки.
- **States:** idle · answer selected · playing (ответ проигрывается; неверный — «призраком») · holding (остановка на событии с подписью) · ended (вердикт + короткое «почему») · paused · resume (вернулся в середину сессии) · offline (контент встроен в приложение).
- **Notes:** заголовка шага и кнопки Continue нет. Шаг-предсказание — одна попытка. Числовой шаг: встроенный калькулятор + выбор единиц (раскладка — открытый вопрос, раздел 9). Выход через `×` сохраняет позицию. Сцена **не показывает** ответ до проверки.

### Session complete
- **Purpose:** закрепить результат и дать следующий шаг.
- **Content:** «You can now…» · итог по шагам (сам / с помощью / разбор) · два вопроса в один тап: `Too easy` · `Just right` · `Too hard` и «Would you use this before the exam?» · необязательное текстовое поле.
- **Primary:** следующая сессия (`Exam workout` после Core, следующий урок после Exam workout).
- **Secondary:** `Back to lessons` · `Replay`.
- **States:** completed independently · completed with help (без стыда).
- **Notes:** серия (+1) появляется в полном MVP.

### Practice
- **Purpose:** экзаменационные вопросы по пройденному.
- **Content:** наборы по темам («Graphs», «SUVAT», «Projectiles», «Mixed»), у каждого — число вопросов и последний результат.
- **Primary:** `Start set` (5 вопросов).
- **States:** locked (пока не пройден урок 2: «Finish Lesson 2 to unlock») · ready · completed.
- **Notes:** Practice player — тот же движок, что Session player; разбор показывается после ответа.

### Progress
- **Purpose:** честная картина прогресса.
- **Content:** серия дней + **heatmap активности** (сетка по дням за последние ~12 недель, интенсивность = сколько шагов решено) · уроки (сам / с подсказкой) · навыки по пунктам программы: «Motion graphs: 3/4 independent» · стартовая карта из оценки уровня (для сравнения «было → стало»).
- **Primary:** — (информационный экран); CTA `Practice weak spots`, если есть слабые места.
- **States:** empty («Finish your first lesson to see progress here» + кнопка) · in progress.
- **Notes:** **никаких выдуманных процентов mastery** — показываем только факты. У новых пользователей heatmap почти пустая — пустые клетки должны выглядеть аккуратно (тонкая сетка, без серой «пустоты»), а сетка начинается с недели первого запуска, а не с года назад.

- **Content:** Account (Sign in / Sign out / Delete account) · Reduced motion · Sound & haptics · Study goal · Retake placement · Reset progress (с подтверждением) · Send feedback · Privacy policy · About / version.

## 5. Контент MVP: модуль Kinematics (IAL Unit 1)

Пункты программы WPH11 (Mechanics), которые покрывает модуль. **Перед сборкой каждого урока сверить формулировки и нумерацию с официальной спецификацией Pearson** (Issue 3). Новая спецификация Pearson стартует с сентября 2027 — пока работаем по текущей.

- уравнения равноускоренного движения в одном измерении (SUVAT);
- построение и чтение графиков s–t, v–t, a–t, включая неравномерное ускорение;
- величины из наклона и площади под графиком;
- скаляры и векторы; сложение векторов; разложение вектора на две перпендикулярные компоненты;
- независимость горизонтального и вертикального движения снаряда;
- Core Practical 1: определение ускорения свободного падения.

### Уроки

Уровни: **Foundations** (база) · **Intermediate** (уровень экзамена — основной) · **Advanced**. Все уроки идут **одним путём на уровне Intermediate** — школа сильная, лёгкое не цепляет. Advanced живёт в сессии Tricky cases (после пилота).

**В пилотную сборку входят 3 урока** (рабочий выбор, владелец может поменять): **L4 Up, stop, down** (сцена уже есть) → **L3 Pick the right equation** → **L2 Read motion from a graph**. L1 и L5 — в полном MVP.

| # | Урок | Ядро | Сцена | Пример задачи (числа проверены) |
|---|---|---|---|---|
| L1 | **Which way is positive?** | Вектор/скаляр, перемещение vs путь, знаки скорости, сложение векторов | Трек + стрелки | 300 м на восток, затем 500 м на запад за 200 с → путь 800 м, перемещение 200 м на запад, средняя путевая скорость 4 м/с, средняя скорость 1 м/с на запад. Challenge: 3 км на север + 4 км на восток → 5 км, ≈53° к востоку от севера |
| L2 | **Read motion from a graph** ⭐ | Наклон = ускорение, площадь = перемещение, площадь под осью отрицательная, касательная для неравномерного движения | Трек; v–t и s–t отдельными видами | v: 0→8 м/с за 4 с, затем 8 м/с 6 с, затем до 0 за 2 с → s = 16+48+8 = **72 м**, a₁ = 2 м/с², a₃ = −4 м/с². Transfer: по кривой s–t выбрать подходящий v–t |
| L3 | **Pick the right equation** | Выбор SUVAT по известному/неизвестному, тормозной путь | Трек (машина); v–t отдельным видом | 20 м/с → 0 при торможении 5 м/с²: v² = u² + 2as → **40 м**. Transfer: удвоить скорость → путь ×4. Challenge: время реакции 0,5 с → +10 м, итого 50 м |
| L4 | **Up, stop, down** | Свободное падение, знаковая конвенция, «v = 0, но a = −g наверху», Core Practical 1 | Вертикальное движение; графики отдельным видом | Бросок вверх 15 м/с, g = 9,81 → до вершины **1,53 с**, h_max = **11,5 м**. CP1: наклон графика s от t² равен g/2 |
| L5 | **Two motions at once** ⭐ | Разложение вектора, независимость осей, снаряд | Projectile Lab: угол/скорость, тени-проекции на оси | С обрыва 20 м горизонтально 15 м/с → t ≈ **2,02 с**, дальность ≈ **30,3 м**. Под 30° со скоростью 20 м/с на ровной площадке → t ≈ 2,04 с, дальность ≈ **35,3 м**. Transfer: при каком угле дальность максимальна (без сопротивления воздуха) |

### Крючки — каждый урок начинается с загадки, а не с определения

Первый шаг каждого урока — **Predict** на реальной ситуации, где интуиция часто ошибается. Рабочие варианты (финальные формулировки — при сборке урока):

| Урок | Крючок |
|---|---|
| L1 | «Бегун пробежал 800 м за 200 с, но его средняя скорость — всего 1 м/с. Как такое возможно?» |
| L2 | «По одному графику скорости скажи, где машина окажется через 12 секунд» — и сцена проигрывает поездку только после ответа |
| L3 | «Машина едет в 2 раза быстрее. Во сколько раз длиннее тормозной путь?» (большинство отвечает «в 2») |
| L4 | «Мяч в верхней точке. Чему равно его ускорение?» (большинство отвечает «нулю») |
| L5 | «Один мяч уронили, второй в тот же момент бросили горизонтально. Какой упадёт первым?» |

Критерий приёмки урока: владелец, проходя урок впервые, хотя бы раз думает «о, интересно» — а не «это я знаю».

(Полный MVP) Оценка уровня (Placement) берёт вопросы из той же логики: короткие шаги predict и build-solution на тех же сценах, ~10–12 штук в банке.

**Экзаменационные вопросы:** в пилоте — 3–4 карточки в Exam workout каждого урока; в полном MVP ещё вкладка Practice, всего 12–15 **оригинальных** вопросов в стиле экзамена (MCQ, расчёт с единицами, график, выбор объяснения). Вопросы и тексты Pearson **не копируем**: прошлые работы — только ориентир по формату и уровню.

### Сцены

- **Большая сцена, один объект в фокусе.** Сцена и график — **отдельные виды** на всю ширину (переключатель или отдельный шаг), оба идут от одной модели и одних часов `t`. Вариант «объект + связанные графики на одном экране» (старый Motion Lab) владелец отверг: на телефоне он нечитаем.
- **Вертикальное движение** (L4) — сделана: посылка с дрона, высота–время отдельным видом.
- **Горизонтальный трек** (L3, L2) — машина/поезд на прямой, v–t и s–t отдельными видами; площадь под v–t закрашивается со знаком.
- **Projectile Lab** (L5, полный MVP) — запуск под углом, компоненты скорости, «тени» движения на осях, след траектории.

Правила сцен: движение строго по физической модели (позиция вычисляется из функции, а не «на глаз»), стрелки привязаны к объектам, есть пауза, повтор и reduced motion, ответ до проверки не раскрывается.

## 7. UX/UI principles для этого продукта

1. **Сцена — главная на экране.** Вид (сцена или график, один за раз) занимает не меньше половины высоты, в сцене один объект в фокусе. Если шаг можно показать — показываем, а не пишем.
2. **Сначала предсказание, потом анимация.** Анимация никогда не выдаёт ответ до проверки. После ответа движение объясняет, *почему*.
3. **Одна главная кнопка на экран.** Внизу, крупная: `Check → Next`. Проигрывание идёт само, кнопок Continue нет. Остальное — второстепенное.
4. **Обратная связь на каждый тап** — визуально + haptic. Правильный ответ — короткое уверенное движение, а не конфетти. Ошибка — что именно не так, без стыда.
5. **Честность прогресса.** Показываем факты (сам / с подсказкой), а не выдуманные проценты.
6. **Физическая точность как часть дизайна.** Оси подписаны, единицы указаны, стрелки привязаны, движение по модели.

**Доступность:** контраст текста ≥ 4.5:1 · touch targets ≥ 44pt · смысл не передаётся только цветом (правильно/неправильно — ещё и иконкой и текстом) · поддержка динамического размера шрифта · reduced motion · подписи для VoiceOver/TalkBack на ключевых элементах.

**Платформа:** нативная навигация (жест «назад» на iOS, системная кнопка «назад» на Android), безопасные зоны, тёмная тема — Later.

### Визуальное направление (бриф для `frontend-design`)

- **Настроение:** умный, взрослый, «живая тетрадь инженера» — точный, но тёплый. Для 16–20 лет, без детскости.
- **База:** светлый, почти белый фон, тёмный текст, много воздуха.
- **Акценты:** 2 насыщенных цвета со смыслом (рабочая идея: синий — движение/скорость, коралловый — ускорение/сила) + один цвет для «правильно». Никаких блёклых пастельных оттенков.
- **Типографика:** один гротеск с характером для крупных заголовков + хорошо читаемый текстовый шрифт + табличные цифры для чисел и формул. Пока системный шрифт; пару выбрать на реальном экране.
- **Графики:** тонкие точные линии, подписанные оси, цветовая привязка величин одинаковая во всех уроках.
- **Референсы:** Brilliant (сцены и тактильность), Duolingo (короткие сессии, ясный следующий шаг), но без копирования их стиля.
- **Нельзя:** фиолетовые градиенты по умолчанию, glassmorphism, эмодзи вместо иконок, одинаковые сетки карточек везде, маскоты, игрушечные машинки и однотипные шарики, случайные AI-картинки, «бессмысленное покачивание» объектов.

| 5 | **3. Exam workout L4 + Home + веб-ссылка** | Числовой шаг с калькулятором, экзаменационные карточки, экран Home, сессия доступна по ссылке | Дать ссылку 2–3 одноклассникам, молча посмотреть |
| 6–7 | **4. L3 Pick the right equation** | Сцена «горизонтальный трек», Core + Exam workout | Проверка физики и уровня |
| 8–9 | **5. L2 Read motion from a graph** | Графики v–t и s–t отдельным видом, площадь со знаком, Core + Exam workout | Проверка физики и уровня |
| 10 | **6. Пилот** | 15–30 учеников по веб-ссылке, опрос, итоги | Раздать, собрать отзывы |

Неделя 10 попадает на январскую сессию IAL. Запасной вариант: начать пилот раньше на двух уроках (после этапа 4), третий добавить по ходу.

**Полный MVP (после пилота, порядок уточняем по его итогам):** L1 и L5 + Projectile Lab → сессии Tricky cases → Review → онбординг с оценкой уровня → аккаунты и синхронизация → вкладки Practice и Progress, streak, heatmap → сборки для сторов.

**Правило при отставании:** качество сцен и уроков не снижаем и «пока так» не выпускаем. Сначала сдвигаем пилот или начинаем его на меньшем числе уроков.

### 8.4 Риски

| Риск | Вероятность | Что делаем |
|---|---|---|
| 2 ч/нед. мало, сроки сползут | Высокая | Пилотная сборка из 3 уроков вместо всего MVP; у каждого этапа один результат; пилот можно начать на 2 уроках |
| Вход Apple/Google сложнее, чем кажется (dev build, настройки консолей) | Средняя | Отдельный этап после пилота; до этого всё работает на анонимном аккаунте, так что задержка входа не блокирует уроки |
| Данные несовершеннолетних пользователей | Средняя | Собираем минимум (без имени и возраста), Privacy policy, удаление аккаунта; перед публикацией проверить требования сторов и GDPR |
| Placement отпугивает в начале | Средняя | Вопросы на сценах (это «вау», а не анкета), ≈ 90 с, `Skip` всегда виден; меряем долю дошедших до конца |
| Анимации тормозят на Android | Средняя | Измерить на реальном устройстве при первом запуске; запасной путь — Skia |
| Уроки слишком лёгкие для сильной школы | Средняя | Intermediate по умолчанию, задачи-ловушки уровня экзамена, сессии Tricky cases, опрос «Too easy» с первого теста |
| Дизайн выглядит шаблонно | Средняя | `frontend-design` перед каждым новым экраном, выбор из вариантов на реальном экране, скриншот-ревью после каждого визуального изменения |
| Ошибки в физике | Низкая/критичная | Ответы вычисляются кодом, тесты, ревью Егора |
| Нарушение авторских прав (копия вопросов Pearson) | Средняя | Только оригинальные вопросы; прошлые работы — ориентир по формату |
| Ограничения Expo Go (нужна нативная библиотека) | Низкая | Выбираем библиотеки из Expo Go; при необходимости — dev build |
| Смена спецификации в 2027 | Известно | Контент привязан к `SpecPoint`, обновим по пунктам |
| Экзамены/поступление съедают время | Высокая в январе | Цель — закончить основную работу до январской сессии IAL; резервные недели могут выпасть на январь — тогда пауза без потерь |
| Аккаунты разработчика Apple/Google требуют совершеннолетнего | Известно | Пилот идёт по веб-ссылке; до сборок для сторов решить, кто из взрослых оформляет аккаунт |
| Пилот без входа: нельзя отличить тестеров друг от друга | Средняя | Случайный идентификатор устройства без личных данных (если владелец согласует счётчики); первые 2–3 сессии — наблюдение и заметки от руки |

### 8.5 Что проверяем на реальных людях — и как

1. **После этапа 2:** владелец сам проходит полную Core-сессию на телефоне — контрольная точка «вау».
2. **После этапа 3:** 2–3 одноклассника проходят сессию по ссылке на своём телефоне, ты молча смотришь (без подсказок!). Записываешь, где застряли и что сказали вслух.
3. **Этап 6:** пилот на 15–30 учениках. Считаем количества: сколько начали, сколько дошли до конца сессии, на каком шаге бросили, ответы на два вопроса.
4. **После пилота:** 3 клипа сцен в Instagram → смотрим, какой цепляет. Это первая проверка канала УБТ.

**Не выдумываем** интервью, отзывы и цифры. Если данных нет — пишем «нет данных».
