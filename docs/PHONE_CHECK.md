# Проверка на телефоне (для владельца)

## Как открыть
1. На компьютере в папке проекта: `npx expo start`
2. Телефон и компьютер — в одной Wi-Fi. На телефоне установи **Expo Go**.
3. Узнай IP компьютера: `ipconfig getifaddr en0`
4. Expo Go → **Enter URL manually** → `exp://<IP>:8081` (или отсканируй QR-код из терминала).
5. Для чистой проверки: Me → Settings → Reset progress, потом встряхни телефон → **Reload** (прогресс на телефоне сотрётся). Welcome появится, только если на этом телефоне его ещё не проходили.

## Что проверить (отмечай галочками)
**Первый запуск**
- [ ] Welcome: пружина с шайбой тянется пальцем и качается после отпускания
- [ ] Выбор сессии экзамена, потом сразу первый урок

**Вкладки**
- [ ] Home · Learn · Revise · Me переключаются плавно, без пружин
- [ ] Home: карточка «продолжить» с картинкой, строка повторения
- [ ] Learn: экран курсов → карта курса → стрелка «Courses» назад
- [ ] Revise: большая карточка повторения и плитки Practise a level / Mistakes / Mock set / Notebook
- [ ] Me: серия, 12 недель, шайбы уроков, спецификация, Settings

**Один урок целиком** (например, «Which way is positive?»)
- [ ] Обложка и главы (плашка при входе в главу)
- [ ] Новые виды заданий: sort, estimate, build, spotError, worked, graphPick, order, examCard
- [ ] Момент «ага» — вспышка рамки и PUZZLE SOLVED
- [ ] Lesson complete → Your breakdown → Next lesson / Back to the map
- [ ] Level complete (после последнего урока уровня): предмет падает и отскакивает

**Звук и вибрация**
- [ ] Звуки верно / неверно / «ага» / уровень
- [ ] Беззвучный режим: звуков нет, вибрация по настройке

**Плавность фигур** (на телефоне важнее всего)
- [ ] «Viscous drag» — линии тока (Flow)
- [ ] «Drawing the forces» — ящик (Crate)
- [ ] Лифт («The push from the floor»)
- [ ] Прокрутка урока: фигуры замирают за экраном и продолжают

**Тема и доступность**
- [ ] Settings → Dark: все экраны читаются
- [ ] Системные «Reduce Motion»: ничего не движется, всё в конечном состоянии
- [ ] Кнопки легко нажимаются большим пальцем

Что не понравилось или сломалось — пришли скриншот и одну строку: что и на каком экране.
