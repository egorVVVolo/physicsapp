# Physicsapp (working name)

Interactive physics lessons for **Pearson Edexcel International A Level Physics — Unit 1**.
See the physics move, then answer like the examiner wants.

- First module: **Kinematics** — motion graphs, SUVAT, free fall, projectiles.
- Platforms: iOS, Android and web from one codebase (Expo / React Native).
- Status: **early development** — MVP planned for the end of 2026.
